# 누락·부분 확보

기준 범위 65~79회 문제지·정답표·웹 정답은 15회 모두 확보했다. 아래는 **분석이 끝나지 않은** 항목이다.

## 이미지 PDF (전 페이지 텍스트 추출 불완전)

`pdftotext` 한글이 거의 없는 회차: 65~69, 73~74, 78~79.

- 79회: 렌더링 원본을 보고 AI 원본 대조 50문항 완료. 사람 검수 0.
- 78회 및 기타 이미지 회차: Tesseract가 문항 번호 `N.`를 일부만 잡는다(대략 22~32/50). 잡은 구간만 키워드 자동 분류. **회차 완료로 세지 않음.**
- 전 페이지 OCR을 다시 돌리려면 `python3 scripts/exam-patterns/run.py extract --ocr-pages` (로컬 `var/`만 갱신).

## 텍스트 PDF

70·71·72·75·76·77회는 bbox로 1~50번 영역을 모두 붙였다. 분류는 키워드 휴리스틱(`auto`). 시각 자료 필수 여부는 렌더를 보지 않아 `null`.

## 이의 공지 미확인

공지 검색에서 해당 회차 게시물을 못 찾은 경우 정정 없음을 단정하지 않는다. `manifest.json`의 `answer_correction.corrected`가 `null`인 회차를 본다 (작업 시점 67·77회).

## 79회 이후

`sources/later-rounds.md`. 80·81회는 일정만 있고 문제지 미공개. 65~79 집계에 섞지 않음.

## 이용 허락

앱 재배포 허용은 확인하지 않음. `sources/terms-and-reuse.md`.
