# 학습 정책과 공통 계약 게이트

개정: 2026-09-11. **목표 설계**이며, 아래 개념/필드/API가 이미 구현됐다고 가정하지 않는다. 구현 기준은 현재 소스와 검수한 PR이다. 과거 동결 계약은 `../archive/redesign-v1/contracts.md`에 보관한다.

## 제품 정책 — 확정 방향
- 목표 급수·시험일 또는 미정·학습 경험·학습 요일을 받는다. 개념 완주일과 최종 복습 기간을 시험일에서 역산한다. 촉박한 계획에는 남은 분량을 사실대로 제시한다.
- 일반 학습의 분량은 개념/문제/복습 개수 중심이다. 고정 120분, 카드 1.2분, 문항 2.2분을 제품 약속으로 사용하지 않는다. 실전 제한 시간과 일반 학습 시간은 분리한다.
- 처음 배우는 개념: 설명 → 비교/예시 → 확인 문제 → 피드백. 복습은 배운 범위에서 회상·비교·다른 자료 적용으로 반복한다.
- 진도는 완료 기반. 날짜가 바뀌거나 결석해도 미완료 내용을 건너뛰지 않는다. 같은 날 재개 목록과 진행을 보존한다.
- 새 학습은 현재 개념/단원 안에서, 누적 복습은 이전에 배운 모든 시대에서 선정한다. 현재 같은 시대만 허용하는 복습 필터는 전환 대상이다.
- 문화사는 시대별 내용에 함께 연결하고 종합 비교도 제공한다. 기존 `culture` ID를 삭제하여 과거 기록을 깨뜨리지 않는다.
- 자료실과 오늘 학습은 같은 기록 서비스를 사용한다. 단순 열람은 완료가 아니다. 동일 문항 연속 정답만으로 숙달을 판정하지 않는다.
- 이해/암기/실전 비율과 복습 간격은 검증 가능한 설정값이다. 고정 학습 효과·합격 보장으로 표현하지 않는다.

## 현재 호환성 기준
`src/types/index.ts`, `src/types/contracts.ts`, `src/lib/studyService.ts`, `src/db/`가 기준 브랜치의 실제 계약이다. `startOrResumeSession`, `recordQuizAnswer`, `finishSession`, 백업·복원·시드 병합을 변경하면 기존 호출자와 함께 이전한다.
- DB 삭제/reseed 금지. 추가 필드·구형 백업은 명시적 버전 변환으로 처리한다.
- 사용자 편집 카드, 오답 카드, 완료 이력, 진행 중 세션, 모의 답안 스냅샷을 보존한다.
- 새로고침/다중 제출/저장 실패/구버전 복원 테스트를 작성한다. 실패한 가져오기는 기존 DB 불변.
- 날짜 계산은 사용자 날짜 기준, 시험일이 지났거나 미정인 경우를 처리한다.
- 응답 시간 미측정은 null. 정답 판정·숙련도에 가짜 시간이나 일괄 속도 감점을 넣지 않는다.

## 평가·이미지·UI
- 실전 50개 고유 문항, 현재 80분 구조 유지. 부족하면 불가 상태/연습 모드를 제공하며 ID 패딩 금지.
- 배점 분포는 참고값이고 공식 고정 난이도 비율이 아니다. 학습에 노출된 문항은 평가 결과에 표시하고 미노출 평가와 구분한다.
- 합격 확률·안정권을 근거 없이 표시하지 않는다. 자동 포맷 검사와 역사적 정확성·변별력 검증을 구분한다.
- 유물 사진은 권리·출처·식별 정확성 검수. 생성 이미지에는 재현 여부, 승인 상태를 기록한다. PNG/벡터 선택은 용도 기준이다.
- 실제 `src/index.css`의 디자인·Pretendard를 기준으로 한다. `/library`와 `/timeline` 호환, 검색 query, focus 복원, 읽기 폭·긴 문장·키보드 접근을 보존한다.
