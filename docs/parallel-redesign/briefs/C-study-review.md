공유 타입·DB·API·CSS는 총괄 계약을 따른다. 문서의 목표 기능을 구현 완료로 가정하지 않는다. 소유 경로 밖의 변경은 의존성으로 보고한다.

## 요구 사항
- 첫 학습은 개념 설명 → 확인 문제 → 해설 → 복습 → 결과.
- 새 문제는 현재 단원, 누적 복습은 이미 배운 모든 시대. 출제 이유 표시.
- 오답 원인에 맞는 설명/비교/회상 제공. 동일 문제 연속 정답과 숙련 구분.
- 구체적인 회상 질문 유지. 무조건 4지선다 카드로 되돌리지 않는다.
- 중단·새로고침·저장 실패·원인 건너뛰기·편집 카드·중복 제출 방지 보존.
