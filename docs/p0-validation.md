- TypeScript `tsc -b --pretty false`, `oxlint src`: 통과.
- Vite production build: 통과. JS 약 598 KB / gzip 약 185 KB. 500 KB chunk 경고는 남아 있으며 실행 오류는 아니다. 경고 제거를 위해 콘텐츠를 삭제하거나 제한값만 높이지 않았다.
- `node --test scripts/automation/audit.test.mjs`: 3개 통과.
- 콘텐츠/변경 영향 감사: **구조 오류 0, 검수 경고 94**. 경고는 출처/문항 검수 부족이며 역사 사실이 틀렸다고 판정한 수치가 아니다.

## 확인한 실패/보존 경로

동시 답안 저장, 부분 저장 실패 rollback, 자정 이후 세션 ID/목록 보존, 요청 단원 범위, 같은 시대 미학습 카드 제외, 설명만 읽고 완료 금지, 불가능한 날짜 거절, 손상된 개념/문항 스냅샷 복원 거절, 모의 결과/답안의 원자적 제출과 중복 방지, 자료실 저장 실패 후 동일 시도 재시도를 검증했다.

실제 fake-indexeddb v2 스키마를 만든 뒤 v3 앱으로 열어 사용자 편집 카드·시도·진행 세션을 대조했다. v1 백업 호환/현재 백업 왕복, v2 백업 복원, 테이블 삭제 이후 쓰기 실패 시 rollback을 검사했다. 사용자의 실제 브라우저 DB를 삭제/초기화하지 않았다.

## 화면 확인 범위

로컬 `http://127.0.0.1:43127/`와 자료실 개념 탭을 확인했다. 기존 미완료 세션은 유지되고 홈은 이어서 학습과 개념/문제/복습 분량을 표시한다. 학습 시간 약속을 제거했다.

자료실 선사·고조선에서 7개 설명, 출처 링크, 긴 회상 질문, 펼친 기대 답안을 확인했다. 375px와 1280px는 화면으로 가독성을 확인했으며 320/768/1280px에서 문서 너비가 viewport를 넘지 않음을 DOM 측정으로 확인했다. 임시 viewport는 원래 크기로 복구했다.

전체 모바일 기기, 200% 확대, 전체 키보드 동선, 공개 URL, 날짜 이동을 포함한 전체 학습 E2E는 아직 검증하지 않았다. 자료실 답안 저장/오류 처리는 컴포넌트 테스트로 검증했고 사용자의 실제 이력에 시험 답안을 추가하지 않았다.
