## 실행 증거

- 전체 Vitest **195개/42파일 통과**. 분량/과정 8개, 부분 세션·복원 8개, 읽기 확인/실패 UI 2개를 추가했다.
- TypeScript `tsc -b --pretty false`, `oxlint src` 통과.
- Vite production build 통과. JS **621.69 KB / gzip 191.83 KB**. 기존 500 KB chunk 경고는 남아 있다.
- 콘텐츠 집계: 설명 7개 / 미준비 81개 / 명시적 개념 연결 문항 8개 / 출처 URL 8개 / 본문 텍스트 자료 46개 / 실제 이미지 0개 / 실측 변별력 0개.
- `content-coverage.mjs --check` 통과. audit 규칙 테스트 3개 통과, 감사 구조 오류 0·검수 경고 94. 홈 분량 문구 조정 후 관련 10개 회귀도 재검증했다.

Cursor 별도 worktree에서는 균등 정답 위치의 100문항 고정 기대값과 fake-indexeddb 모듈 해석이 실패했다. 총괄이 기대값을 개수에 독립적인 균등 분포 검사로 바꾸고 설치된 통합 worktree에서 검증했다. lockfile/의존성 버전은 바꾸지 않았다. 문항은 번들 데이터이므로 기존 카드 seed 버전은 유지한다.

## 새로 검증한 실패·보존 경로

- 88개 안정 ID의 중복/누락, 문화사 중간 배치, 남은 학습일과 권장량, 쉬는 날·미래 시작·과거 목표·과도한 분량.
- 하루 1개 설정 시 해당 개념만 설명하고 관련 문항만 배정. q-51 등 미학습 의존 개념이 남은 문항 제외.
- 회상 확인을 저장하지 않으면 완료하지 않음. 선택 개념만 완료하며 자료실 열람이나 과거 단원 완료를 임의의 개념 완료로 바꾸지 않음.
- 객관식 신규 문항이 없는 날의 회상 확인을 기록하되 점수·시도를 생성하지 않음.
- 준비된 7개 뒤 여러 나라에서 멈추고 전체 완주일은 미확정으로 유지.
- 자정·목표 변경·가이드 수정 후 같은 범위/원본 유지. 저장용 원본과 화면 반환 객체 모두 복사.
- 자료실에서 q-79를 풀어도 q-02 등 같은 단원의 다른 미학습 문항을 복습에 넣지 않음.
- 개념 저장 실패 시 day/concept/session 원자 rollback, 완료 중복 방지, 완료 당일 새로고침 시 같은 분량 재생성 방지.
- 새 목표/확인 체크/가이드 원본 백업 왕복, 손상된 개념 범위·계획 거절. 실제 v2 DB 이전과 v1/v2 백업 호환 회귀도 유지.

이전 테스트의 단원 완료 조건은 명시적 legacy 단원 연습으로 유지하고, 자동 계획에서 과거 단원 이력을 근거로 미확인 개념을 건너뛰던 기대값은 새 정책에 맞춰 변경했다. 실패 검사를 삭제해 통과시킨 것이 아니다.

## 화면 검증과 한계

실제 로컬 앱의 설정·자료실·홈을 브라우저에서 확인했다. 설정에는 목표일/시험일/요일/분량과 81개 미준비 안내가 나오고, 자료실에는 보강된 7개 설명·8문제가 표시된다. 사용자의 기존 9월 9일 미완료 세션은 원래 목록으로 이어지고 새 분량을 덮어쓰지 않는다. 사용자 DB 초기화나 가짜 답안 기록은 하지 않았다.

이번 브라우저 viewport 375px 요청은 실제 크기에 반영되지 않아 **관측된 639px 화면**에서만 육안·문서 너비 검사를 확인했다. 임시 viewport는 reset했다. 신규 읽기 확인·저장 실패는 컴포넌트 테스트로 검사했다. 실제 375px/데스크톱/200% 확대·전 과정 브라우저 E2E·공개 URL 확인은 이 묶음의 통과 범위가 아니다.
