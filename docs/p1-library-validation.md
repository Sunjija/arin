# P1-04 자료실 재개 통합 검증

확인일: 2026-09-11. 기준 브랜치 `codex/arin-design-v3`, 시작 `999bb0c52fae1921c32670547ef2630418519923`. API `0b56a6d`, DB/백업 `7f26486`, Cursor UI 제출 `00a900a` → 반입 `3722f76` 후 이 문서와 함께 보완한 소스 기준이다. 이전 목표·분량 검증은 [P0 기록](p0-validation.md)에 보존한다.

## 구현과 데이터 보존

- 자료실 단원별 문제 순서·원본·선택·해설·결과를 저장한다. 시작 당시 원본으로 계속 풀며, 다시 풀기는 명시적 새 세션이다. 기존 답안은 유지한다.
- 자료실 저장 API가 공통 recordAnswer를 사용한다. 답안·오답·숙련도·개념 진행·피드백 단계가 같은 트랜잭션으로 저장된다. 실패 시 전부 되돌리며, 반복 제출/다음 클릭으로 답안이나 문항을 중복 진행하지 않는다.
- 자료실 session ID와 revision으로 오래된 창의 변경을 거절한다. 오늘 학습의 현재 세션·하루 계획·단원 완료를 자료실 풀이가 덮어쓰지 않는다. 오늘 학습 자체의 다중 탭 revision 정책까지 해결한 것은 아니다.
- DB v4가 libraryPractice를 추가하며 v3/v2의 카드·답안·진도·진행 세션을 보존한다. 재시드는 진행을 지우지 않으며, 사용자가 명시적으로 선택한 초기화만 자료실 진행도 함께 지운다.
- 백업 v4는 모든 테이블을 하나의 읽기 트랜잭션에서 내보낸다. 진행 단계·답안 대응·중복 ID를 복원 전에 검사하고, 전체 복원도 하나의 쓰기 트랜잭션으로 처리한다. v1/v2/v3 백업을 읽되 과거에 저장하지 않은 자료실 위치를 추정하지 않는다.

## 실제 브라우저 검증

사용자의 43127 포트 학습 DB를 건드리지 않도록 **127.0.0.1:43228**의 별도 테스트 서버/origin에서 UI 조작만 수행했다. 검증 뒤 테스트 탭과 서버를 종료했다.

- 미제출 선택 후 새로고침: 선택 유지, 해설 비공개.
- 답 확인 후 새로고침: 같은 해설·문항 복원. 다음 이동 후 새로고침: 다음 문항 복원.
- 8문항 완료 후 새로고침: 결과 `4/8` 복원. 다시 풀기: 1번 문제로 시작. 이 점수는 테스트용 임의 선택 결과다.
- 같은 진행을 연 두 창에서 서로 다른 선택: 오래된 창의 변경 거절, 안내 후 저장된 최신 선택 복구. 원문 예외가 붙는 문제를 수정하고 재검증했다.
- 검색 0건 상태의 `지우기`로 돌아왔을 때 진행 복원.
- 375×812, 320×812에서 선택/긴 지문·해설/하단 버튼을 화면으로 확인했다. Space 선택·Enter 제출·Tab 초점 이동을 확인했다.
- 768×1024에서는 문서 폭, 1280×900에서는 문서 폭과 실제 화면을 확인했다. 각 폭의 scrollWidth는 innerWidth와 같았고, 검사한 문제 본문·보기의 수평 넘침이 없었다. 임시 viewport 설정은 해제했다.

200% 글자 확대, 실제 모바일 기기, 전체 자료실/연표 전수 검증은 미실행이다. 저장 실패는 fake-indexeddb 주입 테스트로 검증했으며 실제 사용자 디스크 오류를 만들지 않았다.
