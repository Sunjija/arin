# 콘텐츠 제작·인수 기준

2026-09-13. 목표는 한국사 심화 개념 이해와 반복 학습을 연결하는 것이다. 내부 88개 목록은 편집 초안이며 공식 전 범위 분석 완료를 뜻하지 않는다.

## 제작 단위

현재 편집 순서의 다음 공백부터 2–3개 개념씩 제작한다. 하나의 묶음은 설명, 혼동 비교, 자기 회상, 서로 다른 평가 과제의 확인 문제, 사실 출처, 검수 기록을 포함한다. 개념당 두 문제를 출발점으로 삼되 문항 수만 채우는 변형은 인수하지 않는다. 기존 적합한 문항은 출처·버전·개념 연결을 검토하여 재사용할 수 있다.

## 학습 목적

- 개념 학습: 원인→변화→결과, 선후 관계, 비슷한 인물·제도 구분을 이해시키고 자기 말로 회상하게 한다. 쉬운 인식·회상 문항도 목적에 맞으면 유지한다.
- 자료 적용: 자료의 단서로 대상을 식별하고 관련 사실을 연결하거나 순서/인과/비교를 판단한다. 답을 질문에 주고 지문은 장식으로 두지 않는다.
- 실전 평가: 최근 기출의 확인된 시대·주제·배점·평가 능력·자료 유형을 매칭한다. 분석하지 않은 회차를 완료로 집계하거나 임시 비율을 공식 비율로 표시하지 않는다. 학습용 제작 완료를 실전 승인으로 자동 승격하지 않는다.

## 필수 인수 조건

1. 사실·출처: 실제 열어 확인한 국사편찬위원회/공식 박물관 등의 근거를 주장별로 기록. 기관 도메인의 글이라도 집필자 해석과 확정된 사실을 구분한다. 역사 용어·정형화된 사실은 억지로 바꾸지 않는다.
2. 설명: 선수 지식과 이번 목표를 밝히고 모바일에서 읽기 쉬운 짧은 문단으로 구성. 연도 나열만으로 설명을 대체하지 않는다. 회상 질문의 예상 답은 실제로 가르친 범위에서 나온다.
3. 정답: 평가 과제가 명확하고 정답이 하나. 부정형 질문과 해설의 정오가 일치한다. 참인 사실을 틀리다고 쓰는 대신 그 인물·시기·대상과 왜 맞지 않는지 설명한다.
4. 오답: 같은 시대·인접 제도·혼동 인물을 활용. 정답의 길이·구체성·문법 또는 다른 선지끼리의 모순만으로 풀리지 않게 검토한다.
5. 자료: 해석에 실제로 쓰는 단서를 포함. 재구성 자료는 학습용 재구성으로 표시하고 역사적 발언을 창작해 실제 사료처럼 제시하지 않는다. 필요한 사진/지도 없이 유형 이름만 자료형으로 붙이지 않는다.
6. 해설: 핵심 단서, 정답 근거, 모든 오답의 이유, 복습할 개념. 불필요한 문량보다 잘못 판단한 지점을 설명한다.
7. 독창성·권리: 기출 지문·상황·자료 배열·선지 조합 복제나 동의어 치환 금지. 원문/문제지 이미지는 배포물에 넣지 않는다. 이용 조건이 확인되지 않은 사진은 사용하지 않는다.
8. 기록·검증: 안정된 ID, 실제 개념/단원, 계열 ID, 내용 버전, 출처·확인일·실제 검수 주체를 기록. 기존 세션/과거 시험/오답 스냅샷은 그대로 유지. 타입·lint·회귀·빌드와 집계를 확인한다.

사실 오류, 복수/무정답, 해설 모순, 필수 자료 누락, 불명확한 자료 권리는 차단 사유다. 정답 노출과 무의미한 오답은 학습 목적을 고려해 편집한다. 자동 구조 통과는 역사 전문가 승인이나 실전 품질 인증이 아니다.

## 제작과 검수의 역할

Cursor: 출처 수집·원문 대조, 설명/문항 초안 구현, 해당 데이터 테스트와 검수 기록 작성. 별도 worktree/명시된 파일 범위에서 로컬 커밋한다.

Codex 총괄: 기존 문항/출처와 독립 대조, 정답·오답·자료 단서 검토, 필요한 편집, 공유 API/스냅샷 통합 회귀. 단어만 바꾼 변형을 별도 평가 계열로 세지 않는다. Cursor 결과를 무검수 자동 병합하지 않는다.

사람 전문가: 역사 정확성·기출 평가 능력·난이도 적정성의 최종 편집 승인. 실제 검수가 없으면 미실시로 남긴다. 현재 소스 스키마가 제작 목적/사람 승인 전체를 표현하지 못하는 항목은 검수 문서로 명시하고 별도 데이터 계약 작업으로 남긴다.

초안→AI 출처 대조→총괄 AI 편집→사람 승인→출시 채택을 구분한다. 원문 guide의 source-checked는 AI 대조를 포함할 수 있으며 approved와 다르다. 배점은 실측 난이도·변별도와 별개다. 기존 약 49% 평가는 주관적인 표본 편집 평가로만 유지하며 이번 생산량으로 재계산하지 않는다.

풀이 데이터가 생기면 첫 응답과 반복 응답, 문항/계열 노출, 오답 선택 분포, 응답 누락을 분리해 개선한다. 표본·측정 조건을 기록하지 않은 정답률이나 합격 가능성을 만들지 않는다.
