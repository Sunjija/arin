# 개인별 반복학습 구현 기록

대상: 한국사능력검정시험 심화.  
완료 범위: 목표 설정 → 오늘 학습 → 중간 종료 → 이어 하기 → 학습 완료 → 다음 복습 안내.

학습 효과·합격률·기억 유지율이 좋아졌다는 주장은 하지 않는다. 실사용자 데이터가 없다.

---

## 1. 재사용한 것 / 새로 만든 것

재사용: 암기카드 간격반복(`spacedRepetition`), 학습 세션·오답·숙련도(`studyService`), 자체 문항 검수(`inspectQuestions`), Dexie 기존 테이블, 모의 배점 환산(`examScoring`의 점수 계산만).

신규: 오늘 계획 고정 플래너, 목표 온보딩, 짧은 복습과 전체 완료 구분, 시도 스냅샷, 결과 종류(처음/반복/해설 후/확신 없음), 분석·품질 어댑터, 주입 가능한 시계.

별도 SRS 저장소·기출 수집기·관측 비율 집계기는 만들지 않았다.

---

## 2. 일일 선정 규칙과 복습 정책

정책 버전 `daily-learning-v1` (`src/lib/dailyLearningPolicy.ts`).

가정(최적 학습법이라고 표시하지 않음):

- 복습 도래 카드 → 최근 오답/확신 없음 개념 → 커리큘럼 다음 새 개념 → 다른 형식 적용
- 초기 비중 대략 복습 50 / 신규 30 / 적용 20. 상한: 복습 8, 새 개념 2(처음 공부 자기평가는 1), 적용 2
- 밀린 복습은 오늘 상한만 넣고 `nextReviewAt`은 그대로 둔다. 완료 처리하지 않는다
- 같은 날 `studyDays.plan`이 있으면 항목을 다시 섞지 않는다
- 시험 임박 시 복습을 우선하고, 남은 단원 × 추정 시간이 남은 일 × 하루 시간을 넘으면 범위를 다 못 한다고 안내한다. 합격 가능성은 말하지 않는다

시간 추정: 처음에는 휴리스틱, 완료 학습일 5회 이상이면 실제 `minutesSpent`로 보정하고 보정임을 표시한다.

## 3. 학습 상태 의미 / 아직 추정인 것

| 상태 | 의미 |
|---|---|
| 오늘 학습 완료 | 그날 전체 세션을 끝냄. 실전 준비 완료가 아님 |
| 짧은 복습 완료 | 도래 복습만. 오늘 전체는 미완료, 연속 학습 미반영 |
| 기억 확인 | 카드 간격 성공 등. 추정 |
| 추가 확인 | 다개념 문항 오답 등. 모든 개념을 미숙으로 내리지 않음 |
| 적용 | 처음 보는 다른 형식·검수 승인 문항에서 맞힌 경우만 |
| 연습 정답률·배점 구성 | 추정 또는 정답표 참고. 공식 출제 비율 아님 |

자기평가(처음/경험 있음)와 진단은 검증된 실력이 아니다. 진단은 검수 승인 문항이 있을 때만, 건너뛸 수 있다. 현재 은행에는 사람 승인 필드가 없어 진단 풀이 비어 있다.

## 5. 브라우저 확인 순서

1. `/setup`에서 급수·응시일(또는 미정)·하루 시간·경험을 저장한다
2. 홈에서 “오늘은 새 개념 n개와 복습 m개를 공부해요”와 이유를 확인한다
3. 오늘 학습 시작 → 카드/개념/문제 중 홈으로 중간 종료 → 다시 학습에서 이어 하기
4. 끝까지 완료 후 홈의 다음 복습 안내
5. 짧게 복습하기를 쓰면 전체 완료가 되지 않는지 확인
6. 설정에서 목표를 바꿔도 진행 중 답안이 남는지 확인
7. 설정 → 학습일 미리보기 또는 `/?asOf=YYYY-MM-DD`로 날짜를 옮겨 복귀·임박 안내를 본다

저장 실패 배너는 학습 화면에서 IndexedDB 실패 시 “저장 다시 시도”로 확인한다.

---

## 6. 부족한 콘텐츠와 후속

- 사람 검수 승인 문항이 없어 적용 평가·진단은 준비되지 않음으로 안내한다
- 기출 관측 비율은 분석 에이전트 산출 대기. 게이트 통과 전 공식 비율로 표시하지 않음
- 모의고사 스냅샷 조립의 본 구현은 품질 병렬 작업에 맡긴다. 학습 시도에는 문항 스냅샷을 남긴다
- 랭킹·소셜·캐릭터·필기·결제는 제외

## 7. 테스트와 미검증

단위 테스트: `npx vitest run` **63 passed**. 신규/기존, 시험 미정/임박, 복습 과다, 콘텐츠 부족, 승인 문항 없음, 날짜 변경, 세션 유지, 중복 완료, 짧은 복습 vs 전체 완료, 같은 문항 반복 vs 스냅샷 보존, 분석 산출물 거부, 같은 개념 카드 묶기.

타입 검사 `tsc -b` 통과, `oxlint src` 통과, `npm run build` 통과.

브라우저(Playwright + Chrome, 데스크톱·390px):

1. `/setup`에서 1급, 응시일 미정, 40분, 처음 공부 → 저장
2. 홈 헤드라인 “오늘은 새 개념 1개와 복습 8개를 공부해요”, 시간 “아직 추정”, CTA “오늘 학습 시작”
3. 학습 시작 → 카드 1장 답 → 중간 종료 → 홈 CTA “이어서 공부하기” → 카드 2/8로 재개
4. 설정에 급수·응시일·경험·학습일 미리보기 존재

미검증: IndexedDB 저장 실패 강제 재시도(코드 경로는 있음), 짧은 복습을 끝까지 마친 뒤의 화면(단위 테스트로 완료/미완료 구분), 분석 에이전트 산출물 실파일 연동(아직 전달 없음).
