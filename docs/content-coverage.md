## 학습 순서 정리

현재 계획의 미완료 선택은 달력 진도 건너뛰기를 막지만 단원 순서 자체는 기존 week/dayOrder다. 이후에 추가된 lesson-12~18이 뒤에 배치돼 고려·삼국·남북국이 다시 섞인다. **전 범위의 시간순 과정은 아직 완성되지 않았다.**

제안 순서: 선사·고조선 → 여러 나라 → 삼국·가야 → 삼국 전쟁/통일 → 남북국·후삼국 → 고려 전기/중기/후기 → 조선 전기/양란/후기 → 개항·개혁·대한제국 → 국권 침탈·식민 통치·독립운동 → 광복·정부 수립·전쟁·민주화·경제 → 문화사 종합 비교. 각 시대에서 정치·경제·사회·문화를 함께 다룬다.

이 순서는 편집 제안이다. 기존 ID를 바꾸지 말고 명시적 courseOrder/개념 관계를 추가하며 기록 이전을 검증한 뒤 적용한다. 88개 목록 밖의 필수 공백은 아래 공식 자료와 기출 분석으로 추가한다.

## 근거와 자료 제작 방식

- [한능검 공식 시험 안내](https://www.historyexam.go.kr/pageLink.do?link=examGuideline): 심화는 단순 암기뿐 아니라 역사 지식·자료 분석·이해를 평가한다. 앱 완성도는 문제 수만으로 판단하지 않는다.
- [공식 기출 자료실](https://www.historyexam.go.kr/pst/list.do?bbs=dat): 이번 확인에서는 79회까지의 자료를 확인했다. PR #11의 750행은 분석 후보이며 사람 검수 완료 목록이 아니다.
- [우리역사넷 한국사 목차](https://contents.history.go.kr/front/nh/main.do?lang=ko)와 [교과서 자료 목차](https://contents.history.go.kr/mobile/ta/list.do?levelId=ta_m71&treeId=100): 누락 조사에 사용. 과거 교과서 목차를 현행 공식 시험 필수 목록과 동일시하지 않는다.

제작 단위는 `개념 ID → 학습 목표 → 출처/확인일 → 자체 설명 → 비교·회상 → 확인 문항 → 선지 해설 → 자료 적용 → 검수 기록`이다. 재사용 허용 여부는 이미지마다 기록한다. 실제 유물 식별은 실물 자료를 우선하고 생성 PNG는 캐릭터·보상·설명용에 사용한다.

이해/암기 비율은 지금 고정 수치로 확정하지 않는다. 설명 직후 확인, 다음 날 회상, 새로운 자료 적용을 구분해 기록하고 지연 회상 성공·첫 노출 정답률·같은 오답 재발로 조정한다. “듀오링고 방식이므로 효과가 있다” 또는 “문항이 100개이므로 실전 대비가 된다”는 주장은 승인하지 않는다.
