## #14 독립 재현과 수정

원본 `c088090`을 별도 worktree에서 실행: 기존 162개 통과, 별도 작성한 8개 재현 모두 실패. 재현 코드는 `src/lib/learningApi.review.test.ts`에 통합하고 후속 사례를 추가했다.

| 재현 | 수정 |
|---|---|
| 숙련도 저장 실패 후 attempt만 남음 | 답안·오답·숙련도·개념 진도를 한 트랜잭션으로 저장 |
| 같은 attempt 동시 제출이 숙련도를 두 번 갱신 | 트랜잭션 안에서 중복 확인, 정오는 문항 스냅샷으로 판정 |
| lesson-02 지정 시작에 lesson-01 문제 포함 | 요청 단원 전용 새 문제 목록 선정 |
| 자정 이후 미완료 세션 유실 | 날짜와 무관하게 미완료 ID·목록·단계 유지, 홈도 이어하기 표시 |
| 완료 저장 실패 후 일일 완료 ID만 남음 | 일일 기록·단원/개념 완료·메타·세션을 한 번에 저장 |
| 2026-02-31 목표 허용 | 실제 달력 날짜와 숫자 범위 검증 |
| 손상된 v3 개념 진도 백업 허용 | 복원 전 상태·날짜·ID·점수 및 신규 계획/스냅샷 구조 검증 |
| 같은 시대 미학습 단원 카드가 복습에 유입 | 기본 카드의 명시적 단원 관계 사용. 시대만으로 학습을 추정하지 않음 |

추가로 모의 답안도 공통 기록 경로로 통합했고, 실패 시 시험 결과까지 rollback한다. 설명만 읽고 확인 문제를 풀지 않은 세션은 단원 완료로 처리하지 않는다. 재개 문항은 저장된 스냅샷을 우선한다. 새 메타데이터가 없는 구형 시도를 키워드로 임의 이전하지 않는다.
