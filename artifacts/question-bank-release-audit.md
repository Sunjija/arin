# 문제은행 출처·출시 적합성 감사

> 감사일: 2026-09-11  
> 대상: `src/data/questions.ts` 100문항  
> 대조 자료: 국사편찬위원회 한국사능력검정시험 심화 제65~79회 15회분(약 750문항)

## 판정

현재 문제은행이 최근 공식 기출문항을 그대로 복사해 만든 정황은 발견되지 않았다. 문항 전체 문자 유사도는 매우 낮았고, 가장 긴 연속 일치도 역사 교재에서 통상적으로 쓰이는 사실 표현 수준이었다.

다만 이 결과는 “최근 15회 공식 심화 문제지와의 직접 복제 가능성이 낮다”는 뜻이다. 제64회 이전 기출, 시중 모의고사, 인터넷 학습자료와의 관계까지 증명하지는 못한다. 현재 모든 문항에 같은 `자체 제작` 메타데이터만 붙어 있어 실제 집필·검수 이력을 사후 확인할 수도 없다.

따라서 기존 100문항을 즉시 폐기할 필요는 없지만, 출시 전 검수 대기 상태로 두고 문항별 출처 이력과 검수 기록을 채워야 한다.

## 검사 결과

### 직접 유사도

- 비교 범위: 저장소 100문항 대 공식 심화 65~79회
- 비교 단위: 문제 지문과 5개 선지
- 전처리: 공백·문장부호 제거, 한글·영문·숫자 중심 정규화
- 검사: 문자 3~5그램 TF-IDF 유사도와 연속 문자열 일치
- 검사 양성 대조군 점수: `0.7762`
- 저장소 문항 최고 점수: `0.0809`
- 저장소 문항에서 확인된 가장 긴 연속 일치: 정규화 기준 16자

점수 차이가 크고, 문항 전체·지문 전체가 이어서 일치한 사례가 없으므로 직접 복제 신호는 없다.

가장 긴 일치가 나온 문항은 아래와 같다. 모두 사건·제도의 정형화된 사실 표현이다. 역사적 사실을 정확하게 전달하기 위해 통상적으로 쓰이는 표현은 허용하며, 이 일치만을 이유로 문항을 다시 쓰지는 않는다. 문항의 자료 구성·추론 깊이·오답 품질이 부족할 때 함께 개선하고 사실 출처를 연결한다.

| 문항 | 일치한 성격 | 판정 |
|---|---|---|
| q-07 | 이차돈 순교와 불교 공인에 관한 선지 | 허용 가능한 사실 표현 |
| q-74 | 조선 혁명 선언과 의열단에 관한 지문 | 허용하되 문항 구조 개선 시 함께 검토 |
| q-81 | 관료전 지급·녹읍 폐지에 관한 선지 | 허용 가능한 사실 표현 |
| q-29 | 파리 강화 회의 대표 파견에 관한 오답 | 허용 가능한 사실 표현 |
| q-33 | 부정 선거 항의에 관한 오답 | 허용 가능한 사실 표현 |
| q-49 | 1377년 청주 흥덕사에 관한 지문 | 허용하되 자료형 문항으로 개선 권장 |
| q-82 | 국내 진공 작전에 관한 지문 | 허용하되 추론 단서 보강 권장 |

### 생성·편집 흔적

- Git 기록에는 문제은행을 40→85→95→100문항으로 단계적으로 확장하고 오답과 중복을 재작성한 커밋들이 남아 있다.
- `questions.ts`와 조사 문서는 공식 기출 문장·이미지를 사용하지 않는다고 명시한다.
- 정답 위치는 1~5번이 각각 정확히 20개이며, 코드가 문항 순서에 따라 `1→2→3→4→5`로 강제 배치한다. 이는 공식 시험지를 그대로 옮긴 데이터보다 자체 생성·편집 데이터의 특징에 가깝다.
- 위 정황은 자체 제작 주장을 뒷받침하지만 문항별 원자료와 집필자 기록을 대신하지는 못한다.

## 출시를 막는 문제

### P0 — 문항별 출처 이력이 없다

100문항 모두 다음 값만 공유한다.

- `source: 자체 제작 학습문항`
- `sourceUrl: 빈 문자열`
- `license: 학습용 자체 제작`
- `imageRights: 이미지 없음`

이 값만으로는 누가 어떤 자료를 확인하여 작성했고 누가 검수했는지 알 수 없다. `학습용 자체 제작`도 권리 상태를 설명하는 정식 라이선스나 소유권 기록이 아니다.

출시 전 각 문항에 아래 정보를 남겨야 한다.

```ts
provenance: {
  origin: 'original'
  blueprintVersion: '2026-09-v1'
  factSources: [{ title, url, accessedAt }]
  authorId: string
  reviewerId: string
  reviewedAt: string
  rightsStatus: 'cleared'
  similarityAudit: {
    corpusVersion: 'official-65-79'
    maxScore: number
    reviewed: boolean
  }
}
```

### P0 — 실제 시험이 측정하는 자료 해석 능력을 충분히 재현하지 못한다

- 100문항 중 56문항은 별도 지문이 없다.
- 이미지 문항은 0개다.
- 공식 심화 문제지는 지도, 유물·문화재, 회화, 문서, 도표, 대화·탐방 시나리오를 함께 사용한다.
- 현재 은행은 사실 확인형 문장과 텍스트 단서에 치우쳐 있다.

국사편찬위원회가 안내하는 심화 평가는 주요 사건·개념의 종합적 이해뿐 아니라 역사 자료의 분석·해석과 시대 상황·쟁점 파악을 포함한다. 현재 문항은 이 목표의 일부만 훈련한다.

### P0 — 사람의 역사 검수가 증명되지 않는다

자동 검사기는 선지 수, 정답 인덱스, 일부 키워드 반복, 시대가 지나치게 먼 오답 등을 검사한다. 다음 항목은 보장하지 않는다.

- 정답의 역사적 정확성과 단 하나의 정답만 존재하는지
- 표현이 교과서·번역문·시중 문제를 재가공한 것인지
- 사료처럼 보이는 문장이 실제 사료인지, 제작한 요약문인지
- 최신 교육과정과 시험 범위에 맞는지
- 1·2·3점 표기가 실제 난이도와 일치하는지

### P1 — 문제은행 규모가 작다

심화 모의고사 한 회는 50문항이다. 현재 100문항은 중복 없이 구성하면 두 회분에 불과하다. 반복 학습과 개인화 추천을 운영하면 사용자가 빠르게 문항을 외우게 된다.

출시 최소 목표는 사람 검수를 마친 300문항, 안정적인 유료 운영 목표는 800~1,200문항이 적절하다. 문항 수보다 검수 완료 여부를 우선해야 한다.

### P1 — 해설이 학습용으로 짧다

현재 해설 길이의 중앙값은 약 25자다. 정답 근거만 말하는 경우가 많아 오답이 왜 틀렸는지, 어떤 단서를 읽어야 하는지 훈련하기 어렵다.

해설에는 최소한 다음을 포함해야 한다.

1. 자료에서 정답을 찾는 핵심 단서
2. 정답의 역사적 배경
3. 혼동하기 쉬운 오답 1~2개의 반박
4. 연결해서 복습할 개념

### P1 — 정답 위치를 코드에서 순환 배치한다

`balanceAnswerPosition(question, index % 5)`가 모든 문항의 정답을 1~5번 순서로 반복 배치한다. 고정 순서로 문항을 노출하는 화면에서는 규칙을 학습할 수 있다. 모의고사를 만들 때 문항 순서와 선지 순서를 각각 섞고, 저장되는 정답 인덱스를 함께 변환해야 한다.

## 권장 제작 방식

사용자가 제안한 “출제 성향을 분석하고 우리 문제를 새로 만든다”가 맞다. 단순히 기출 문장을 동의어로 바꾸는 방식은 피하고, 학습 목표부터 새로 설계한다.

1. **분석 단계**  
   공식 문제에서는 회차·시대·주제·평가유형·자료 종류·오답 전략·예상 난이도만 기록한다. 원문 문장과 이미지는 제작 명세에 옮기지 않는다.

2. **블루프린트 단계**  
   예: `고려 / 무신 집권기 / 자료 해석 / 2점 / 인접 사건 오답 4개`처럼 문항의 역할만 정의한다. 최소 10~15회 통계를 사용하고 회차가 추가될 때 갱신한다.

3. **독립 집필 단계**  
   집필자는 블루프린트와 사실 확인 자료만 보고 새 상황·새 질문·새 선지를 작성한다. 현대어 번역문도 저작권이 있을 수 있으므로 그대로 옮기지 않고, 필요한 경우 직접 요약하거나 이용 허락이 명확한 자료를 쓴다.

4. **시각 자료 제작 단계**  
   지도·연표·관계도는 직접 제작한다. 문화재 사진은 공공누리·CC 등 이용 조건을 문항별로 기록하고, 공식 문제지 안의 사진을 추출해 재사용하지 않는다. 공식 자료실도 문제지에 사용된 사진 등의 저작권이 원저작자에게 있다고 밝히고 있다.

5. **유사도 검사 단계**  
   공식 기출과 허가받아 구축한 비교 말뭉치에 대해 연속 문자열·문자 n그램·의미 유사도를 검사한다. 점수만으로 자동 삭제하지 말고 상위 후보를 사람이 원문과 대조한다.

6. **이중 검수 단계**  
   한국사 내용 검수와 문항 편집 검수를 분리한다. 정답 유일성, 단서 충분성, 오답 매력도, 표현의 독립성, 이미지 권리, 해설 품질을 모두 통과해야 공개한다.

7. **베타 통계 단계**  
   실제 풀이 데이터를 통해 정답률, 문항 변별도, 선택지별 선택률, 평균 풀이 시간을 수집한다. 난이도는 집필자의 1·2·3점 추정이 아니라 이 통계를 반영해 보정한다.

| 순서 | 작업 | 완료 조건 |
|---:|---|---|
| 1 | 기존 100문항 검수 대기 처리 | 미검수 문항은 운영 배포에서 제외 가능 |
| 2 | 문항 provenance 스키마 추가 | 100문항 모두 사실 출처·집필·검수·권리 상태 보유 |
| 3 | 유사도 검사기를 빌드 작업에 추가 | 새 문항마다 감사 결과 생성, 상위 후보 수동 승인 |
| 4 | 실전성 하위 문항부터 구조 재작성 | 정형 사실 표현은 유지 가능, 자료·추론·오답 품질 개선 |
| 5 | 100문항 역사·편집 이중 검수 | 정답 유일성·사실 정확성·해설 기준 100% 통과 |
| 6 | 이미지·도표·지도형 자체 문항 보강 | 전체의 30% 이상, 문항별 권리 정보 기록 |
| 7 | 검수 완료 은행 300문항 확보 | 비공개 베타 시작 가능 |
| 8 | 베타 결과로 난이도 보정 | 문항별 정답률·변별도·선택지 반응 확인 |

## 출시 판단

현재 문제은행의 출처 복제 위험은 낮아 보이지만, 출시 준비도는 약 **40%**로 본다. 기본 문항 100개와 내부 검사기는 갖췄지만, 문항별 출처 증명, 사람 검수, 시각 자료형 문항, 충분한 문항 수, 실사용 난이도 통계가 아직 없다.

기존 문항은 초안 자산으로 활용하고, 위 제작 공정을 통과한 문항만 `reviewStatus: approved`로 전환해 앱에 노출하는 방식이 가장 안전하다.
