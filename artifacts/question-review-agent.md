# 문제검사 에이전트 리뷰

수동 전수 검사 (40문항). 휴리스틱 리포트(`question-inspection-report.md`)는 error 0으로 나왔으나, 지문–정답 키워드 반복·중복 문항·황당 교차 오답·AI 교과서 문체를 기준으로 재평가하면 **실질 오류급 약 10건**, 경고급 다수.

## 총평

은행 전반은 5지선다·인접 왕조 혼동을 의식한 흔적이 있으나, **source-what/policy-content 설명형이 과다**하고 심화 변별에 필요한 **밑줄·지도(텍스트)·비교·옳지 않은 것**이 거의 비어 있다. 자동 검사는 PASSAGE_COPY를 놓친다—특히 `q-02`(중계 무역 복붙), `q-01`(지문 재서술형 정답), `q-11`≡`q-40`(광종 복제)는 즉시 폐기·재작성 대상이다. 오답이 “다른 시대면 틀린다”로 풀리는 문항(`q-08`, `q-20`, `q-36`, `q-37`)이 많아 한능검 심화 감각에 미달한다.

1. **삭제/교체 배치:** `q-40` 삭제(또는 타 왕 source-who로 완전 교체). `q-02`·`q-01`은 PASSAGE_COPY 금지 규칙으로 전면 재작성.
2. **formatId별 재작성 우선순위**
   - `source-underline` ×2 신설: 조선 수취(대동/균역) ㉠, 개항기 조약 ㉠—정답에 지문 구절 재등장 금지.
   - `map-region` ×2 신설: 평양 천도·강화 천도·한강 확보를 **지명 서술만**으로 묻고 왕은 선지에만.
   - `wrong-statement` ×1~2: 광종/성종 또는 개항기 사건—옳지 않은 한 줄만 인접 시기 오류.
   - `king-compare` ×1: 태종↔세종 또는 광해군↔인조(교재 범위 내).
   - `policy-name` ×1: 균역법·기인·정방 중 하나로 `q-38`과 겹치지 않게.
3. **오답 규칙 강제:** 신규·수정 문항의 오답은 **같은 왕조 또는 ±1 시대**만. 선사↔근현대, 신라↔대동법, 훈민정음↔독립협회 조합 금지.
4. **source-what 신규 중단:** 현재 과잉. 기존 `q-20`·`q-27`·`q-36`은 각각 policy-content / cause-effect / (문자 체계) policy-name 쪽으로 포맷을 바꿔 재배치.
5. **중복 테마 정리:** 광종(q-11/40), 대동법(q-21/38은 포맷이 달라 유지 가능하되 stem 단서 차별화), 세종·훈민(q-19/36)—36 재작성 시 19와 지문 겹침 금지.
