# 한능검 심화 — 출제 자료조사 정리

> 목적: **공식 기출 문장·이미지를 복제하지 않고**, 출제 골격·평가 의도·시대 비중만 정리해  
> 우리 자체 제작 은행의 설계 기준으로 쓴다.  
> 참고: 국사편찬위원회·교육부 안내, 공개된 시험 구조 설명, 학습용 분석 자료.

## 1. 시험 골격 (심화)

| 항목 | 내용 |
|------|------|
| 문항 | 50문항, **5지 택1** |
| 시간 | 80분 |
| 배점 | 1·2·3점 (전형적으로 10·30·10문항 → 100점) |
| 급수 | 1급 80+ / 2급 70+ / 3급 60+ |
| 시대 비중 | **전근대사 ≈ 60% : 근현대 ≈ 40%** (수능과 반대에 가깝게 전근대사 비중 큼) |

## 2. 공식 평가 유형 6종 → 우리 format 매핑

국사편찬위원회가 안내하는 평가 유형:

| # | 공식 유형 | 측정 의도 | 우리 `ExamFormatId` |
|---|-----------|-----------|---------------------|
| 1 | 역사 지식의 이해 | 사실·개념·제도·인물 | `policy-content`, `king-policy-match`, `heritage-period`, `policy-name` |
| 2 | 연대기의 파악 | 순서·연속·변화 | `chronology-events`, `chronology-labeled` |
| 3 | 역사 상황·쟁점 인식 | 자료에서 쟁점·주장 포착 | `source-underline`, `cause-effect`, `wrong-statement` |
| 4 | 역사 자료 분석·해석 | 사료의 시대·사회 의미 | `source-who`, `source-what`, `map-region` |
| 5 | 역사 탐구 설계·수행 | 탐구 절차 (비중 상대적 소) | 현재 MCQ에서는 약하게만 반영 |
| 6 | 결론 도출·평가 | 자료 종합·타당성 | `king-compare`, `wrong-statement` |

실무적으로 **1·2·4유형이 대부분**을 차지한다는 분석이 많다 → 은행도 지식/연표/사료를 축으로 두되, 3·6으로 변별력을 올린다.

## 3. 시대별 출제·학습 포인트 (요약)

| 시대 블록 | 대략 비중 | 빈출 소재 (키워드만) |
|-----------|----------:|----------------------|
| 선사~고조선·초기국가 | 작음 | 유물 표지, 고조선·부여·삼한 |
| 삼국~남북국 | 중 | 전성기 왕, 불교, 통일·발해 |
| 고려 | 중~상 | 제도·무신·대몽·원간섭·공민 |
| 조선 | **최다권** | 통치체제, 수취, 붕당, 문화 |
| 개항~대한제국 | 상 | 조약·개혁·운동 연표 |
| 일제강점 | **상** | 통치 변화, 독립운동 노선 |
| 현대 | **상** | 정부 수립~민주화 흐름 |
| 문화사 | 횡단 | 유물·사상·과학을 시대에 연결 |

## 4. 문항 작성 금지/권장 (우리 규칙)

### 금지
- 공식 기출 **문장·지문·보기·이미지** 복제
- 지문에 나온 표현을 정답 선지에 다시 쓰기
- 오답의 황당 시대 교차 (신석기↔임시정부)
- “정의 암기 한 줄”만으로 끝나는 1차원 문항 양산

### 권장
- 오답 = **인접 시대·유사 제도·혼동 인물**
- 사료형은 **우회 단서** → 인물/사건명 고르기
- 전근대사 60% / 근현대 40% 목표 분포
- 작성 전 `examFormats.ts`의 formatId 선택

## 5. 우리 은행 목표 규모 (1차)

| 구분 | 목표 |
|------|------|
| 학습 단원 | 시대별 핵심 토픽 전 커버 (≥ 20단원) |
| 연습 문항 | ≥ 80 (모의 50 구조 + 여유) |
| 암기카드 | ≥ 80 (왕↔업적·순서 비중) |
| 포맷 | `map-region`·`source-underline`·`king-compare`·`wrong-statement` 등 공백 우선 보충 |

상세 토픽·매트릭스는 `src/data/topicCatalog.ts` 참고.
