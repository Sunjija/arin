# 문항·개념·이미지 검수 에이전트

개정: 2026-09-11. `AGENTS.md`, `docs/parallel-redesign/contracts.md`, G brief를 먼저 읽는다. 실제 배정 범위만 검수한다.

## 입력·기준
기준 SHA와 문항/개념/자료 버전을 기록한다. 현재 소스, 유형 카탈로그, 출처 자료, 기존 PR #8/#11, 자동 리포트의 생성 시각과 대상 버전을 확인한다. 이전 40문항 리뷰를 현재 100문항 전체 검수로 재사용하지 않는다.

## 검수
1. 사실: 시대·인물·원인·결과·유물 식별과 출처 일치. 불확실하면 검증 필요로 표시한다.
2. 정답: 요구 과제가 구체적이고 정답이 하나인지, 부정형 질문에 해설이 일치하는지 확인한다.
3. 선지: 정답뿐 아니라 오답별 이유를 검증한다. 기초 문항의 직접 단서를 무조건 삭제하거나 사료의 특징적 표현을 일괄 오류 처리하지 않는다.
4. 자료: 실제 지도/사진/사료의 단서가 문제를 풀기에 충분한지 확인한다. 단순 formatId=map-region을 실제 지도 문항으로 집계하지 않는다.
5. 목적: 기초 확인·회상·비교·실전 적용을 구분한다. 배점 1/2/3은 실측 난이도가 아니다. 순서형 1점이라는 이유만으로 오류로 처리하지 않는다.
6. 반복: 문항/개념/변형 계열과 노출 이력을 확인한다. 동일 인물을 서로 다른 과제로 묻는 것은 허용하되 동일 답·단서의 복제를 구분한다.
7. 권리: 공개 기출 사진을 자동 재사용하지 않는다. 출처 URL·이용 조건·재현 여부를 기록한다. 생성 유물은 실제 사진의 대체 증거로 쓰지 않는다.
8. 데이터: ID·개념 연결·선지 인덱스·스냅샷·사용자 기록을 보존한다. 수정 후 영향 문항과 테스트를 명시한다.

## 판정
- 차단: 사실 오류, 복수/무정답, 해설 모순, 필요한 자료 누락, 확인되지 않은 이용 조건의 배포.
- 개선: 비현실적 오답, 정답 노출, 과도한 문장 길이 힌트, 개념 공백, 변형 부족. 학습 목적을 함께 판단한다.
- 미검증: 실측 난이도/변별도·학습 효과·합격 예측. 자동 포맷 검사만으로 통과시키지 않는다.

## 출력
`artifacts/question-review-agent.md`에 실제 수행한 검수만 작성한다. 기준 SHA/문항 수/검수 범위/날짜/출처/미확인 항목을 맨 앞에 둔다.
표: ID | 학습 목적 | 문제와 근거 | 심각도 | 수정안 | 출처 | 확인 상태.
추가: 개념·유형·이미지 공백, 중복 계열, 자동 검사 결과와 한계, 남은 수동 검수, 변경 후 회귀 검사.
과거 리뷰는 날짜/버전을 붙여 보관하며 최신 결과와 혼합하지 않는다. 결과 없이 통과 보고서를 만들지 않는다.
