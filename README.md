# 한사코치 (hanguksa-coach)

한 사람을 위한 **한국사능력검정시험 심화** 맞춤 학습 MVP입니다.  
브라우저 IndexedDB에 학습 기록이 저장되며, 공식 기출 문장·이미지를 복사하지 않은 **자체 제작 학습문항**만 사용합니다.

## 1차 개편 (진행 중)

공통 UI·데이터 계약은 [`docs/parallel-redesign/contracts.md`](docs/parallel-redesign/contracts.md)를 따른다. 페이지 담당 지시문은 [`docs/parallel-redesign/README.md`](docs/parallel-redesign/README.md).

전역 메뉴는 오늘 / 복습 / 자료실 / 실전 / 내 기록 5개다. 화면 숫자는 연습 정답률과 최근 실전 연습 평균으로 분리하며, 측정 전이면 비운다.

## 실행

```bash
npm install
npm run dev
```

- 스크립트: `npm test` · `npm run typecheck` · `npm run lint` · `npm run build`
- 설치형 앱: [`docs/mobile/dev-preview.md`](docs/mobile/dev-preview.md) · 계약 [`docs/contracts/mobile-platform-v1.md`](docs/contracts/mobile-platform-v1.md)

## 학습 알고리즘

1. **암기카드 간격반복** (`lib/spacedRepetition.ts`)  
   모름 1일 / 헷갈림 3일 / 맞음 7일 / 너무 쉬움 14일. 연속 성공 시 ≈2배, 최대 60일.

2. **숙련도** (`lib/mastery.ts`)  
   정답·오답, 최근성, 응답 시간, 오답 원인(인물·순서 혼동 가중) → 0~100.

3. **오늘의 문제** (`lib/questionSelection.ts`)  
   취약 40% · 오답/복습 30% · 오늘 학습 20% · 유지 10%.  
   왕·업적 / 연도·순서 가중 1.5배. 세션 내 중복 금지.

4. **예상 점수·안정권** (`lib/scoreEstimate.ts`)  
   모의고사 최근 3회 가중 평균(3:2:1). 없으면 연습 정답률 추정.  
   목표 점수(기본 85) 이상 **3회 연속**이면 안정권.

5. **모의고사 배점** (`lib/examScoring.ts`)  
   업로드된 77·78·79회 **심화 정답표** 배점 빈도(1점 10 · 2점 30 · 3점 10 = 100점)를 참고합니다.  
   샘플 문항 `difficulty` = 배점(1|2|3), 선택지는 심화형 5지선다.  
   모의고사는 배점 합을 100점으로 환산하며, 문항 은행이 부족하면 축소 모드(기본) 또는 고유 id 패딩으로 50문항 구조를 유지합니다.  
   **공식 기출 문장·이미지는 사용하지 않습니다.**

6. **오답 → 카드**  
   `cardFingerprint`로 앞뒤 동일 내용 중복 방지.

## 난이도 캘리브레이션 메모

답지(정답·배점만)를 기준으로 한 조정:

| 배점 | 의미(앱 내부) | 샘플 비중 목표 |
|------|----------------|----------------|
| 1점 | 기초 사실·대표 유산 | ≈20% |
| 2점 | 표준 제도·인물 | ≈60% |
| 3점 | 왕·업적 구분, 사건 순서, 사료 단서 | ≈20% |

현재 샘플 35문항 분포는 1점 7 · 2점 21 · 3점 7입니다.

## 문항 품질 기준

전 문항을 다음 기준으로 재검토했습니다.

- 오답은 시대가 동떨어진 ‘황당 선지’가 아니라 **인접 시대·유사 제도·혼동 인물**
- 사료형은 지문 베끼기로 맞히지 못하게 **추론형**으로 구성
- 1점≈필수 사실, 2점≈표준 구분, 3점≈순서·비교·함정
- 공식 기출 문장·이미지는 사용하지 않음 (`자체 제작 학습문항`)

현재 은행: 40문항, 배점 분포 약 20·60·20.

### 문제유형 수집·검사

1. 유형 카탈로그: `src/data/examFormats.ts` (한능검 심화 출제 골격)
2. 자동 검사: `npm run inspect:questions` → `artifacts/question-inspection-report.md`
3. 검사 에이전트 지침: `agents/question-inspector.md`

- **암기카드**: 뒤집기가 아니라 **4지 선지 선택**. 틀리면 잠시 뒤 같은 세션에서 다시 출제.
- **맞춤 문제**: 사료/시대 단서 → 선지 → 채점. 오답 원인 기록 후 카드화 가능.
- 문항 문체는 심화 시험의 사료형·순서형·왕·제도 연결형을 참고해 **자체 제작**했습니다.

1. **레슨** — `src/data/lessons.ts`
2. **문제** — `src/data/questions.ts` (`source: "자체 제작 학습문항"`, 공식 기출 문장 복사 금지)
3. **카드** — `src/data/cards.ts` (왕↔업적·연도 순서 비중 권장)
4. 기존 DB는 설정 → 샘플 복원으로 갱신
